# Янтарный циркуль · студия кинематографичных заставок

Единый редактор для всех роликов вечера: сцены 01–11 (интро, фон, спонсоры,
фотопауза, финал и две кинематографичные лаборатории) живут в одном кадре,
одном пульте и одной панели настроек, и записываются в видео одним и тем же
покадровым экспортом.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ — один index.html + папка video/
```

## Что где

| Файл | Роль |
| --- | --- |
| `index.html` | экран загрузки, холст сцены (`#stage`), DOM-слой титров, тост |
| `src/studio/main.js` | точка сборки студии: конфиги сцен, пульт, панель настроек, запись |
| `src/studio/scenes/catalog.js` | каталог роликов: id, код программы, подписи, умолчания |
| `src/studio/scenes/nav.js` | единый список роликов для пульта, вкладок и цепочки |
| `src/studio/operator.js` | нижний пульт: ролики, таймлайн, транспорт, запись |
| `src/studio/ui.js` | панель ⚙: разделы настроек, JSON, варианты A/B |
| `src/studio/editor.js` | покадровый редактор слоёв (сцены 01, 02, 08, 09) |
| `src/studio/fx-stack.js` | общий набор эффектов поверх кадра любой композиции |
| `src/studio/styles.css` | весь интерфейс; токены хрома — в начале файла |
| `src/studio/lab2/` | лаборатория 10 «Золотой рой» |
| `src/studio/lab5/` | лаборатория 11 «Монолиты» (кинофильм 51 с) |
| `video/` | исходные ролики вечера для монолитов |

## Ролики на монолитах (лаборатория 11)

Фильм посещает десять видеомонолитов: на каждом экране — ролик из папки
`video/`. Источники описаны один раз в `src/studio/lab5/media.ts`
(`MEDIA_CLIPS`): имя файла, короткое имя, таймкод вечера и длительность.

* Панель ⚙ → «Лаб. 11 · Ролики на монолитах» — по одному селектору на слот,
  плюс быстрые команды «Все ролики» и «Очистить слоты».
* Пустой слот — осмысленное состояние: на экране остаётся плейсхолдер, а не
  чёрный прямоугольник, и пульт показывает `ролики: N/10`.
* «Что видно в окне визита» — окно монолита около 1,9 с, а ролики длятся от
  1,15 до 14,4 с. Политика решает, показывать начало (`cut`), кульминацию
  (`center`, по умолчанию) или весь ролик ускоренно (`speed`).

Чтобы добавить ролик: положите файл в `video/` и допишите строку в
`MEDIA_CLIPS`. Путь кодируется автоматически — пробелы и кириллица в именах
поддерживаются. В production-сборке папка `video/` копируется в `dist/`
плагином из `vite.config.ts`.

## Единый интерфейс

Пульт, панель настроек и редактор используют один набор токенов (`:root` в
`styles.css`): поверхность, рамку, радиус, шрифт, шкалу подписей и состояния
кнопок. Список роликов тоже один (`scenes/nav.js`), поэтому кнопки пульта,
вкладки настроек и состав автопоказа не расходятся.

## Управление

* `Space` — пауза, `←`/`→` — кадр, `F` — полный экран, `S` — настройки.
* Запись идёт покадрово: предпросмотр и MP4 собираются одним и тем же путём,
  поэтому кадр в файле совпадает с экраном.
