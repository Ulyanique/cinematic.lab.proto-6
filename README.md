# Янтарный циркуль · студия кинематографичных заставок

Единый редактор для всех роликов вечера: сцены 01–11 (интро, фон, спонсоры,
фотопауза, финал и две кинематографичные лаборатории) живут в одном кадре и
одном хроме, и записываются в видео одним и тем же покадровым экспортом.

Открывается студия на анимации «Рой» (лаборатория 10) — это первое интро
программы; остальные ролики выбираются выпадающим списком сверху.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ — один index.html + папка video/
```

## Ролики на монолитах (лаборатория 11)

Фильм посещает десять видеомонолитов: на каждом экране — ролик из папки
`video/`. Источники описаны один раз в `src/studio/clips.ts` (`CLIPS`): имя файла,
короткое имя, таймкод вечера и длительность. Тот же список питает подписи в
кадре и выпадающий список роликов, поэтому «ролик» везде означает одно и то же.

* Панель ⚙ → «Лаб. 11 · Ролики на монолитах» — по одному селектору на слот,
  плюс быстрые команды «Все ролики» и «Очистить слоты».
* Пустой слот — осмысленное состояние: на экране остаётся плейсхолдер, а не
  чёрный прямоугольник, и пульт показывает `ролики: N/10`.
* «Что видно в окне визита» — окно монолита около 1,9 с, а ролики длятся от
  1,15 до 14,4 с. Политика решает, показывать начало (`cut`), кульминацию
  (`center`, по умолчанию) или весь ролик ускоренно (`speed`).

Чтобы добавить ролик: положите файл в `video/` и допишите строку в `CLIPS`. Путь кодируется автоматически — пробелы и кириллица в именах
поддерживаются. В production-сборке папка `video/` копируется в `dist/`
плагином из `vite.config.ts`.

## Интерфейс: слои слева, настройки справа

Хром повторяет референс `cinematic.lab.proto-2`: янтарь на почти чёрном,
стеклянные панели со скруглением 16 px, «таблетки» кнопок.

* Сверху по центру — выпадающий список роликов. Это единственное место, где
  ролик переключается; пульт снизу отвечает только за транспорт и запись.
* Слева — круглая кнопка слоёв, справа — круглая кнопка настроек. Панели
  висят поверх кадра, тянутся за заголовок, сворачиваются двойным кликом и
  притухают, когда мышь не на них.
* Левая панель — список слоёв по группам (монтаж, текст, кадр, свет, декор,
  эффекты, лаборатории). Строка выбирает слой, «глаз» включает и выключает
  его, не открывая настроек.
* Правая панель — параметры выбранного слоя. Все поля схемы доступны: числа,
  переключатели, цвета, списки, тексты, загрузка логотипа. Двойной клик по
  названию параметра возвращает значение по умолчанию, точка слева от
  названия отмечает изменённое. Вкладки панели: «Слой» (параметры), «Кадр»
  (разрешение, качество, кодек, запись, ссылка на сцену и сброс) и «JSON»
  (экспорт, импорт, варианты A/B).
* Список слоёв и инспектор питаются одним источником — схемой разделов, —
  поэтому «настроить можно всё» и не бывает параметра, до которого нет пути.

## Управление

* `Space` — пауза, `←`/`→` — кадр, `L` — слои, `S` — настройки, `Esc` — закрыть
  панели, `R` — закрепить пульт.
* Запись идёт покадрово: предпросмотр и MP4 собираются одним и тем же путём,
  поэтому кадр в файле совпадает с экраном.
